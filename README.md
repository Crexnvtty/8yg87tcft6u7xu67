# WhatsApp-бот для записи клиентов

Простой бот записи на услуги (парикмахер/мастер) через WhatsApp. Работает через
Twilio + вебхук на Node.js. Данные хранятся в SQLite (файл `bookings.db`,
создаётся автоматически).

## Что умеет
- Показывает меню (записаться / мои записи / отменить запись)
- Показывает список услуг, свободные даты и время
- Сохраняет запись, шлёт подтверждение
- Раз в день (09:00) шлёт напоминание тем, у кого запись завтра

## Важно про "внешний вид"
В **бесплатной песочнице Twilio (Sandbox)** доступны:
- форматирование текста (жирный, эмодзи, переносы)
- быстрые ответы обычным текстом/цифрами (то, что использует этот бот)

Настоящие WhatsApp-кнопки и списки (нажал — выбрал, без ввода текста),
а также имя/логотип бота в контакте — становятся доступны только после
перехода на **подтверждённый бизнес-номер** (WhatsApp Business Profile,
проверка через Meta, обычно несколько дней). Это отдельный платный шаг,
делается уже после того, как вы решите, что бот того стоит.

Сейчас бот использует пронумерованные текстовые меню — они работают
одинаково надёжно и в песочнице, и потом на боевом номере.

## 1. Установка

```bash
npm install
cp .env.example .env
```

## 2. Регистрация в Twilio (бесплатно)

1. Зайдите на https://www.twilio.com/try-twilio и зарегистрируйтесь
2. В консоли найдите **Account SID** и **Auth Token** — вставьте их в `.env`
3. Перейдите в **Messaging → Try it out → Send a WhatsApp message**
   — там будет тестовый номер (обычно `whatsapp:+14155238886`) и код вида
   `join <два-слова>`
4. Со своего телефона отправьте этот код в WhatsApp на этот номер —
   так вы "подключаетесь" к песочнице и сможете тестировать бота

## 3. Запуск сервера локально

```bash
npm start
```

Сервер поднимется на `http://localhost:3000`.

## 4. Проброс наружу (ngrok)

Twilio должен достучаться до вашего сервера, поэтому локальный `localhost`
нужно "пробросить" наружу:

```bash
ngrok http 3000
```

Скопируйте выданный https-адрес (например `https://abcd1234.ngrok.io`).

## 5. Настройка вебхука в Twilio

В консоли Twilio, в настройках Sandbox (Messaging → Try it out → WhatsApp),
в поле **"When a message comes in"** укажите:

```
https://abcd1234.ngrok.io/whatsapp
```

Метод — **POST**. Сохраните.

## 6. Тест

Напишите боту в WhatsApp с телефона, который подключён к песочнице,
любое сообщение — должно прийти главное меню. Дальше вводите цифры,
как предлагает бот.

## Что настроить под конкретного мастера

- `config.js` — название бизнеса, рабочие часы по дням недели
- В `db.js` секция `seedServices` — список услуг, длительность, цена
  (после первого запуска проще менять прямо в базе, спрошу отдельно
  как сделать простую админку, если понадобится)

## Дальше, когда протестируете

1. Верификация бизнес-профиля WhatsApp через Twilio/Meta (платно, дни на одобрение)
2. Постоянный хостинг (Railway/Render/VPS) вместо своего компьютера
3. Реальный номер под бота (не личный номер мастера)
