# WhatsApp-бот для записи клиентов (Green API)

Простой бот записи на услуги (парикмахер/мастер) через WhatsApp.
Работает через Green API + вебхук на Node.js. Данные хранятся в SQLite
(файл `bookings.db`, создаётся автоматически).

## Что умеет
- Показывает меню (записаться / мои записи / отменить запись)
- Показывает список услуг, свободные даты и время
- Сохраняет запись, шлёт подтверждение
- Раз в день (09:00) шлёт напоминание тем, у кого запись завтра

## Почему Green API, а не Twilio
Twilio требует либо возню с песочницей (нестабильный интерфейс,
ограничения триала), либо платную верификацию бизнеса. Green API проще
для старта: подключаешь свой личный WhatsApp через QR-код (как WhatsApp
Web) — без отдельного номера и без верификации бизнеса на старте.

## 1. Регистрация в Green API

1. Зайди на https://green-api.com → Sign Up (бесплатно)
2. В личном кабинете (cabinet.green-api.com) создай инстанс (Instance) —
   обычно создаётся автоматически при регистрации, называется что-то
   вроде "Instance 11012345"
3. На странице инстанса найди два значения:
   - **idInstance** (набор цифр)
   - **apiTokenInstance** (длинная строка)
4. Отсканируй QR-код своим личным WhatsApp (Настройки → Связанные
   устройства → Привязать устройство) — так бот будет отправлять
   сообщения от имени твоего WhatsApp-номера

## 2. Установка бота

```bash
npm install
cp .env.example .env
```

В `.env` впиши:
```
GREEN_API_ID_INSTANCE=твой_idInstance
GREEN_API_TOKEN=твой_apiTokenInstance
```

## 3. Запуск локально (для проверки)

```bash
npm start
```

## 4. Деплой на Railway (чтобы бот работал 24/7)

1. Загрузи файлы бота в репозиторий на GitHub (все файлы, включая
   обновлённые `server.js`, `reminders.js`, `greenApi.js`,
   `package.json`)
2. В Railway: New Project → Deploy from GitHub repo → выбери репозиторий
3. В Variables добавь:
   - `GREEN_API_ID_INSTANCE`
   - `GREEN_API_TOKEN`
4. Deploy
5. В Settings → Networking → Generate Domain — получишь адрес вида
   `https://твой-бот.up.railway.app`

## 5. Настройка вебхука в Green API

В личном кабинете Green API (cabinet.green-api.com), на странице твоего
инстанса, найди раздел **"Webhook URL"** (или "Settings" → "Webhook"),
и укажи:

```
https://твой-бот.up.railway.app/webhook
```

Включи опцию **"Incoming messages webhook"** (получать вебхуки о входящих
сообщениях), сохрани.

## 6. Тест

Напиши сам себе... точнее, напиши с любого другого номера на свой
WhatsApp-номер (тот, который подключил через QR) — должно прийти главное
меню бота.

⚠️ Важно: раз бот работает через твой личный номер, значит все сообщения,
которые туда придут, будет обрабатывать бот — включая переписку с
друзьями. Поэтому для реального использования (не просто теста) лучше
:
- выделить отдельный номер (недорогая e-SIM или запасная сим-карта)
  специально под бота, и уже на него ставить Green API
- либо использовать этот же номер только как тестовый, пока не решишь
  вкладываться в отдельный

## Что настроить под конкретного мастера

- `config.js` — название бизнеса, рабочие часы по дням недели
- `db.js`, секция `seedServices` — список услуг, длительность, цена
